# SentinelIQ

SentinelIQ is an AI-powered financial health and risk intelligence platform designed to help small and medium-sized businesses understand financial performance, detect emerging risks, and make better decisions using analytics and machine learning.

## Current Stage

The project currently includes:

- FastAPI backend foundation
- Local API server
- Project structure for analytics, machine learning, frontend, testing, and documentation

## Vision

SentinelIQ will combine:

- Financial analytics
- Business health scoring
- Early warning risk detection
- Cash-flow forecasting
- Anomaly detection
- Scenario analysis
- Explainable machine learning
- AI-assisted decision intelligence
